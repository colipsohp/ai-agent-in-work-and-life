# 8月22日 - 整理一堆麻烦的单据

我叫吴迪，28岁，月薪七八千，房贷二十年。

你要问我这辈子最烦什么，除了老婆、领导、丈母娘，就是每周固定的刘主管手里那沓破纸。

今天又到周一。我早上刚坐下，茶杯还没端起来，刘主管就从办公室探出头，手里扬着一沓纸，跟扬着一沓人民币似的，就差喊一声"开奖了"。

"小吴，这周的收据单，整理一下，明天给我。"

我接过来掂了掂，百来张。有打印的，有手写的，还有几张皱巴巴的，边角卷着，像是从哪个快递箱底抢救出来的。手写那几张，字迹比我小学作业还狂野，数字跟数字打架，我眯着眼看了半天，愣是分不清哪个是6，哪个是0。

你说6和0，一个圆圈多一条尾巴，这很难吗？对写字的人来说，很难。我怀疑写单子的人是受过专业训练的——训练内容就是把"6"写得像"0"，把"0"写得像"6"。

"好的领导，明天准给您。"我笑着说。

刘主管满意地点点头，缩回办公室。门一关，我脸上的笑直接摔地上，还弹了两下。

这事，得从头说。每周一，都是这么一沓纸。日期、用途、金额，一张一张对着敲进表格里。上百张单子，搭上大半天，手疼，眼睛疼，脖子疼。

![吴迪手头那沓收据，光看着就头疼](../assets/chapter1/images/收据1.webp)

你问我为啥脖子疼，废话，一下低头看纸，一下抬头看屏幕，能不脖子疼嘛。

敲错一个数，月底对账对不上，财务大姐一个电话打过来，那语气，比催房贷的还冲。上回她在电话里训人，隔着两层楼，我桌上的仙人掌都蔫了。

这回不一样。刘主管前脚回办公室，我脸上还挂着一副愁眉苦脸的苦相，心里已经乐开了花。

就这点破活，还一张一张敲？

上回我偷摸试过一回，拍照发给小汪同学，几分钟就出一张干净的表格。

刘主管倒好，还跟老黄历似的，一周一沓，当个宝贝。说他笨吧，他能当上主管；说他精吧，这种破活他愣是没想过找AI。

笨人当领导，聪明人偷着乐。

我照旧苦着脸回到工位，把那沓纸往桌上一摊，装出要干到天黑的架势。趁没人注意，溜进小会议室，关上门，一张一张拍照。手写那几张，管它6还是0，拍下来交给AI认去。

不到十分钟，照片拍完，整个文件夹，放在电脑桌面上。打开小汪同学把要求说清楚：整理出日期、用途、金额，看不清就问。回工位没一会儿，表格就发回来了，我对着原单核了一遍，改了两处。然后我把那沓纸往键盘旁边一摊，手机架在屏幕边上，装模作样地一张张翻——其实看的是综艺，一下午连看了好几集。

刘主管中途路过两回，看我对着那沓纸眉头紧锁，还拍了拍我肩膀："辛苦了啊小吴。"辛苦？我辛苦啥，我比谁都闲。

快到下班点，我把表格发给刘主管，附一句"领导，这周的整理好了"。他回"收到"，又补了个大拇指。

我合上电脑，把那沓纸往抽屉里一塞，哼着歌出了公司门。这班上的，跟放假似的。这AI，值了。

## 附

**五步，照抄就能用：**

1. 拍清楚：亮处一张张拍，别糊，别挡字。
2. 说清楚：照片在哪、要哪些内容（日期、用途、金额）、看不清就问。
3. 看着它干：它会自己停下来问。
4. 核对：对着原单查，改错。
5. 检查，交差。
