# 引言

> 这本书写给谁、讲什么、怎么读。

## 为什么写这本书

2026 年，AI Agent 已经不止会聊天了。它能读文件、能查资料，把交代给它的活从头到尾干完。我自己做了一个 AI 助手，叫"小汪"（wang.vocvx.com），工作上的方案、会议纪要，生活里的各种杂事，都扔给它。用了很久，越用越顺手。

可我慢慢发现，用上 AI Agent 的人，大多挤在互联网圈子里。回老家、走亲戚、看楼下的店，多数人眼里的 AI 还停在"会写作文的机器人"。在逛一个服饰批发市场时，老板还在把一张一张的单据手工录入Excel，厚厚的一沓各类单据，估计要录入半个小时。她每天都要付出这么多时间做这件事。而这件事其实AI Agent已经能很好的完成。

所以我想写这本书。虽然我擅长写教程，但教程容易看着困，这次我换了个写法——写一个普通人的日记，吴迪的日记。他 28 岁，在一家普通公司干行政，没写过一行代码，不懂技术。书里他遇到的破事，你多半也遇到过；他用 AI Agent 把事办成的每一步，你也学得会。

他行，你也行。这就是我写这本书的理由。AI的浪潮，每个人都应该受惠其中。

## 这本书讲什么

全书就是吴迪的日记。

工作上，他在一家"具体做啥不重要"的普通公司，对付爱画饼的领导、加不完的班、深夜发来的"明早要 PPT"。生活上，他帮当老师的媳妇备课，帮全家做出游计划，过着和每个人都相似的普通日子...。

每篇日记都是：麻烦来了，吴迪先吐槽三句，再把 AI Agent 用起来，一步步把事办成。每一步都拆开写给你看，照着做就能复现。

书里吴迪把他用的 AI 叫为"小汪同学"。我想讲的就一句：AI Agent 不挑人，谁会用，谁受益。

## 这本书怎么读

没用过 AI？没关系，看看吴迪的故事在你身上有没有影子。哪天你冒出一句"还能这么整？"，这本书就算没白写。

读的时候可以边看边做。吴迪的标准跟你一样：别让我弄乱七八糟的技术，我要的就是搞定事情。

你不用会任何技术。有手机，就能用，有电脑更好。

这本书开源。GitHub 上能读原文，在线书站、PDF、EPUB 都有，怎么方便怎么读。

## 配套素材说明

每章的后面都会附上这一章吴迪用的AI现场的链接，处理事情的源文件，例如单据照片，数据Excel文件等。拿起来就可以复刻。
