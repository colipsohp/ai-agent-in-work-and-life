# 9月2日 - C盘满了

> 读完这一章，跟着吴迪让 AI 自己把电脑翻一遍，看明白 C 盘到底被什么塞满了。哪个能清、哪个不能动，一条条讲成大白话，不用再对着五十多个 G 的大文件干瞪眼。

## 4.1 电脑卡成了老太太

晚上回家，吴迪打开电脑，想查个东西。

双击浏览器，转了三圈，没开。又双击，又转。任务栏的圈圈转啊转，他盯着看了半分钟，骂了一句："今儿这电脑是喝了假酒？"

网页好不容易打开了，点一下，卡一下。他气得把鼠标一摔："这破电脑，越用越卡。"

李娟在客厅听见了，头都没抬："卡就卡呗，你又不是程序员，还能给它治治？"

"我不治。我看看是谁占着茅坑不拉屎。"

吴迪这人，认准的事非得搞明白。他点开"此电脑"，看了一眼 C 盘。

C 盘那一栏，蓝条变成了红条。底下写着一行小字：可用空间 15.0 GB。

他记得这台电脑是 200 个 G 的盘。200 个 G，用剩 15 个，用了九成二。

搁以前，他会当成没看见。这半个月他学了个乖——电脑慢，八成就是这红条闹的。他决定，跟这红条干一架。

## 4.2 清理软件扫了一圈，没扫明白

吴迪先用了电脑里现成的清理软件，点了一下"深度扫描"。屏幕转了几分钟，结果就两行字：

临时文件，能清 2 个多 G。回收站，空的。没了。

他又点了一下"大文件扫描"。这回列出来一长串：视频、安装包、压缩包……七零八落凑一块，五十多个 G。

可这软件只管"列"，不管"说"。每一行就仨字段：文件名、大小、路径。这文件是干嘛的、能不能删、删了会不会出事，一个字不提。

吴迪挨个看。有的看得懂：一个叫"XX安装包.exe"，2.4 个 G——安装包，装完就能删。有的看不懂：一个叫 AppData 的文件夹，里面全是英文名的小文件夹，加起来十几个 G，他一个都不认识。还有 C 盘根目录那个 Windows 文件夹，他听人说过"别乱动"，可为啥不能动、里面装的啥，他说不上来。

鼠标在那个 AppData 上悬了半天，他还是没敢点删除。

五十多个 G 躺在那，他一个都不敢动。跟家里堆了一屋子杂物似的，看着碍眼，可哪件能扔、哪件丢了要命，他说不清。

"这不科学啊。折腾半天，啥也没清着。"他嘟囔了一句。

## 4.3 小汪同学不光会聊天

晚上躺床上，吴迪翻来覆去，脑子里还是那个红条。

忽然想起一档子事。他记得小汪同学的介绍页上有几个字，当时没细看——"看屏幕、点鼠标、敲键盘"。他当时以为是说它能在手机上演示操作，现在一琢磨：这意思，是不是说它能自己动手？

他翻身坐起来，打开电脑，小汪同学还醒着。

"小汪同学，我电脑 C 盘满了，你帮我看看是啥占的。"

屏幕转了两圈，小汪同学回话了：

"能看。我能截屏、点鼠标、敲键盘、读文件、列文件、运行命令。不过在你这台电脑上动手，得先经你同意。我打算先以只读方式扫一遍 C 盘，只看不改，不动任何文件，扫完给你一份报告。你同意吗？"

吴迪盯着屏幕，愣了半天，冒出一句："还能这么整？"

他琢磨起"只读"俩字，呼出一口气："只读？就是啥也不删？"

"对，第一遍只看不改。报告给你，哪些能清、哪些不能动，你来定。"

吴迪点了同意。屏幕上弹出一张卡片，列了一串权限：截屏、点击、输入、读文件、列文件……每一项后面跟着一个开关，都是亮的。最下面一行小字："目标设备：本机电脑"。

他一条条看完。这一串权限要干什么，写得清清楚楚，没有藏着掖着的。他点了一下"允许"。

## 4.4 只读，先翻一遍

同意了，吴迪就看着小汪同学干活。

屏幕上的鼠标自己动了起来。先点开"此电脑"，再点进 C 盘，一个文件夹一个文件夹地进去看。有的文件夹打不开，它也不硬闯，掉头去下一个。中间它开了一个黑底的窗口，在里头敲了几行字，屏幕上刷刷滚过一串串英文和数字。

吴迪看不懂窗口里滚的是啥，但他看得懂一件事：这家伙干活有章法。左边翻完翻右边，上头翻完翻下头，跟老会计对账似的，一笔一笔来。

翻到 Windows 那个文件夹，它停下来，弹出一行字：

"系统文件夹太大，扫了一半就超时了。这个文件夹一般得占五十到八十个 G，是系统本身，建议不动。我继续扫其他位置。"

吴迪回了个"继续"，往后靠了靠。

又过了一阵子，它说："扫完了。出报告。"

## 4.5 报告出来，讲的是人话

报告是一张表，吴迪一眼就看懂了。

第一行是总况：这台电脑一共 199.11 个 G，已经用了 184.09 个 G，剩下 15.02 个 G。跟他下午在"此电脑"里看见的红条对得上。

第二张表，是地盘分布：

| 地方 | 占了多少 | 是啥 |
| --- | --- | --- |
| Windows 系统文件夹 | 大约四成 | 电脑的命根子，删了系统就瘫 |
| 用户文件夹 | 大约四成 | 你的文档、桌面、下载、视频 |
| Program Files | 15.59 G | 你装的软件 |
| ProgramData | 8.33 G | 软件共用的数据 |

吴迪看到"Windows 占四成"，心里咯噔一下。他下午还琢磨，是不是该把 Windows 文件夹里的东西删点腾地方。他把那行字来回看了两遍。那玩意儿占地方，可它必须在那。

第三张表，是"能安全清理"的：

| 项目 | 大小 | 说明 |
| --- | --- | --- |
| 临时文件 | 6.22 G | 程序用完剩下的垃圾，删了不影响 |
| 浏览器缓存 | 642 兆 | 网页缓存，删了头回开网页慢一点 |
| 系统缓存 | 273 兆 | 其中 Windows 更新缓存 198 兆，清完没法回退更新，慎动 |

它最后还补了一句："这三样全清，能腾出大约 7.1 个 G，可用空间从 15 个 G 涨到 22 个 G 左右。另外你的视频文件夹 0.77 个 G、桌面 0.32 个 G、下载文件夹 0.1 个 G，这些是你自己的东西，我没动，你自己看看还要不要。"

吴迪拿着这报告，对照下午清理软件甩给他的那串大文件，咂摸出味儿来了。

下午那个软件，给他看的是"这儿有五十多个 G，你自己看着办"；小汪同学给他看的是"这六个 G 是垃圾，放心清；那几十个 G 是系统和软件，动了就出事；剩下几个 G 是你的东西，自己定"。

一个把包袱甩给他，一个把包袱拆开摆桌上。

## 4.6 清完，蓝条回来了

报告底下，小汪同学问了一句："要不要我帮你清？我建议先清临时文件和浏览器缓存，这两样最安全。Windows 更新缓存先留着，你想回退系统的时候还有得用。"

吴迪想了想："清吧。就清你说的那两样。"

"好。再确认一遍：删除临时文件 6.22 G、浏览器缓存 642 兆，共约 6.8 G。其他文件一律不动。确认吗？"

吴迪又看了一遍那两行字，说："确认。"

屏幕上的鼠标动起来。那个黑底窗口里，一行一行滚出字：正在删除哪个文件夹、清出了多少。吴迪坐在那，盯着看，手指在桌沿上一下一下地敲。

几分钟，窗口滚完最后一行字。

"清理完成。临时文件清了 6.2 个 G，浏览器缓存清了 640 兆。你看一眼 C 盘。"

吴迪点开"此电脑"。C 盘那一栏，红条变成了蓝条，可用空间从 15 个 G，变成了 21 个 G 多。

他盯着那个蓝条看了半天，冒出一句："这不科学啊。"

搁以前，他得自己下个清理软件，挨个文件夹翻，提心吊胆地删，删完还怕删错。这回从它开始扫到清完，前后一个钟头，他就做了三件事：同意扫描、同意继续、确认删除。

他掏出手机，把这回的经验记在小本上：

- 电脑慢，先看 C 盘红没红。红了就是快满了，别硬撑。
- 清理软件只管"列"，不管"说"；问会动手的 AI，它能告诉你哪个能清、哪个不能动。
- 能安全清的就三类：临时文件、浏览器缓存、系统缓存。不能动的是 Windows 系统文件夹和软件本体。
- 让 AI 动电脑，先看它要什么权限。只读的最省心；真要删，让它一项项说清楚，你一条条确认。

李娟哄完豆豆出来倒水，看见吴迪蹲在电脑前傻乐。

"又捣鼓你那 AI 呢？"

"嗯。今儿它帮我清了七个 G 的垃圾，C 盘不红了。"吴迪指着屏幕，"你看，蓝条。"

李娟凑过来看了一眼，问："清了七个 G？那你电脑能快点了不？"

"那必须的。"

"那正好。"李娟把水杯放下，"豆豆的动画片我存你电脑里了，一集两个 G，够存三集半的。"

吴迪脸上的笑，僵了一下。

"……那它下次清理，你可得让它看着点，别把豆豆的动画片清了。"

## 小结

吴迪自己总结的就三句：

1. 电脑慢，八成是 C 盘满了。别自己瞎删，先问会动手的 AI。
2. 会动手的 AI 能自己翻电脑，把"哪个能清、哪个不能动"讲成大白话。
3. 让 AI 动电脑之前，先看它要什么权限；只读的最省心，删东西一项项确认。

## 想一想

1. 你电脑的 C 盘还剩多少？点开"此电脑"看一眼，红了没有？
2. 你上次用清理软件，是不是也遇到过"列了一堆大文件、就是不敢删"的处境？
3. 如果让 AI 帮你扫电脑，你最想让它先回答你哪个问题——哪些能删，还是哪些不能动？
